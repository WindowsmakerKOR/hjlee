# LEE HWA JOO 홈페이지

## GitHub Pages 업로드
압축을 푼 뒤 `index.html`, `style.css`, `script.js`, `assets` 폴더를 저장소 최상위에 업로드하세요.

## 게시물 기능
02 FISHING, 03 RUNNING, 04 CAMPING 메뉴에서 WRITE 버튼으로 사진과 글을 등록할 수 있습니다. 목록은 제목과 썸네일로 표시되며 한 페이지에 10개씩 나타납니다.

## 중요 안내
현재 버전은 별도 서버가 없는 GitHub Pages용 정적 홈페이지이므로 게시물은 해당 브라우저의 localStorage에 저장됩니다. 즉, 글을 작성한 기기와 브라우저에서만 유지되며 다른 방문자에게 자동 공유되지는 않습니다. 모든 방문자에게 같은 게시물을 공개하려면 Firebase, Supabase 같은 데이터베이스 연결이 추가로 필요합니다.
